The tool uses YouTube API Services. By using it, users agree to the YouTube Terms of Service. Google's Privacy Policy applies to data accessed through YouTube API Services.

Only data about our own channel: video metadata, captions and channel analytics (views, watch time, subscribers). We do not access other users' or channels' data.

The data is used only to manage our channel and plan content. It is stored on our own computer. It is never sold or shared with third parties.

Stored API data is deleted or refreshed within the periods required by the YouTube API Services Developer Policies. Access can be revoked at any time at https://myaccount.google.com/permissions. To request deletion, contact sasanana9094@gmail.com.
